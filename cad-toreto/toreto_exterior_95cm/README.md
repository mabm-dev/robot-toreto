# Robot Toreto — piezas exteriores de 95 cm

Diseño por módulos basado directamente en la referencia visual aportada. El
trabajo se organiza en este orden:

1. Base.
2. Tronco.
3. Hombros y pecho.
4. Cabeza y cuello.
5. Brazos y manos.

El alcance incluye únicamente carcasas, paneles y acabados visibles. No incluye
ruedas, motores, servos, ejes, rodamientos, chasis, esqueleto ni anclajes.

## Módulos conservados

- `src/`: fuentes paramétricas OpenSCAD y exportadores de los cinco módulos.
- `docs/`: cotas, despiece y límites de cada módulo.
- `exports/`: STL exteriores separados por módulo.
- `renders/`: vistas de comprobación estética.

Los STL de esta carpeta son piezas exteriores de referencia. Antes de fabricar
hay que revisar espesores, tolerancias, uniones y compatibilidad con el hardware
real que se seleccione.
