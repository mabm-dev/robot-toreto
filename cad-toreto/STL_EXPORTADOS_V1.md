## Recomendacion

Para ver el parecido, abre primero la vista previa. Para imprimir, abre cada STL en Bambu Studio y orienta manualmente las piezas. Esta V1 esta pensada como maqueta visual cercana a la imagen. Para hacerla funcional, el siguiente paso es adaptar agujeros y soportes a motores, ruedas, pantallas y rodamientos reales.
