# Toreto_Base_95cm

Crea dentro de `01_BASE` una primera base CAD nativa a escala real:

- faldón y banda sensora;
- carcasas blancas superior e inferior;
- anillos y tapa superior;
- cuatro ruedas mecanum como piezas exteriores visuales;
- sensores frontales y torreta superior.

No crea motores, ejes, rodamientos, estructura ni electrónica. La revisión
1.2 usa ruedas radiales a 45 grados, paneles frontales redondeados, faldón
negro con cubiertas laterales blancas, torreta elevada y una tapa superior
continua. Al ejecutarla sobre la revisión anterior, sustituye solo
los cuerpos `BASE95_` creados por esta secuencia y no genera duplicados.
