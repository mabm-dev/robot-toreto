# Toreto_Parametros_95cm

Inicializa la única tabla vertical vigente del robot según la lámina maestra:

`200 + 190 + 150 + 190 + 60 + 160 = 950 mm`

Ejecutar primero en un documento de Fusion nuevo o antes de regenerar módulos.
Después ejecutar `Toreto_Componentes_95cm`, los generadores de piezas y, al
final, `Toreto_Alinear_Montaje_95cm`.
