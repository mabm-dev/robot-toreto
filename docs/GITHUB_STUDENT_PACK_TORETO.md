# GitHub Student Developer Pack para Robot Toreto

Revisión: 25 de agosto de 2026  
Fuente oficial: <https://education.github.com/pack/>

## Objetivo

Registrar qué beneficios vigentes del GitHub Student Developer Pack pueden
aprovecharse en Robot Toreto y cuándo conviene activarlos. Las condiciones y
ofertas pueden cambiar; se debe volver a comprobar la página oficial antes de
canjear una promoción.

## Prioridades para el proyecto

| Prioridad | Beneficio | Uso previsto en Robot Toreto | Momento recomendado |
| --- | --- | --- | --- |

| Muy alta | GitHub Pro | Repositorios privados, ramas, revisiones y gestión del código | Ahora |
| Alta | GitHub Copilot Student | Asistencia al programar; el chat y los agentes tienen límites propios | Ahora |
| Alta | GitHub Codespaces Pro | Entorno reproducible y pruebas desde otros equipos | Cuando el código del robot esté consolidado |
| Alta | Arduino Cloud, 6 meses | Prototipos, dispositivos y telemetría | Al comenzar la electrónica |
| Alta | Adafruit IO+, 1 año | Paneles, MQTT e integración IoT | Al comenzar la telemetría |

| Media | Appwrite Education | Autenticación, base de datos y panel de control | Cuando se diseñe el servicio remoto |

## Activación recomendada

1. Activar ahora JetBrains, GitHub Pro y GitHub Copilot Student.
2. Esperar para Arduino Cloud y Adafruit IO+ hasta empezar con hardware y
   telemetría.
3. Elegir una plataforma principal entre Azure, Heroku y Appwrite antes de
   activar créditos o plazos.
4. No canjear todavía los dominios: normalmente su año gratuito empieza al
   activarlos.
5. Guardar tokens y claves en un gestor de secretos; nunca incluirlos en el
   repositorio.

## Herramientas que no figuran actualmente en el Pack

Las siguientes herramientas pueden tener licencias gratuitas o programas
educativos independientes, pero no aparecen como ofertas actuales en la página
del GitHub Student Developer Pack:

- DigitalOcean.
- Adobe Substance 3D.
- Unreal Engine.
- Meta Quest Developer Hub.

Se deben tratar como servicios externos y comprobar sus condiciones directamente
con cada proveedor.

## Relación con la fase CAD actual

Estas ofertas no modifican por sí mismas la geometría de Fusion 360. PyCharm
Professional sí ayudará a desarrollar y depurar los complementos paramétricos
de Toreto. Substance 3D y Unreal Engine se reservarán para materiales, renders y
gemelo digital cuando las piezas exteriores de 95 cm estén cerradas.

No se activará ningún crédito, dominio o servicio remoto, ni se subirán archivos,
sin autorización expresa.
